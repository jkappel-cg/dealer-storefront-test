Dealer storefront prototype (Bernardi Automotive Group of Natick)

HOST IT: upload index.html. That is the only file you need.
Fonts (Graphik, Rund Display), logos, badge and map are embedded in it.
No server code, no external requests, no build step.
Open it locally by double-clicking, or put it on any static host.

assets/   Original fonts and images, for reference or reuse.
source/   template.html and build.py (editable source; build.py injects the
          assets into one file). Edit paths in build.py to match assets/.
Notes panel: use the "Notes" button, bottom left, in the prototype.
